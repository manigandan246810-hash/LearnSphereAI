# LearnSphere AI
## Product Dashboard Design Specification for Antigravity AI

# PROJECT OVERVIEW

You are an expert UI/UX Designer, Senior Frontend Engineer, Product Designer, Motion Designer, and Design System Architect.

Your task is to design and build a **modern, premium-quality Learning Management System (LMS)** called **LearnSphere AI**.

This is **NOT** a basic college management system.

The product should feel comparable to products like:

- Notion
- Linear
- GitHub
- Coursera
- Udemy
- Duolingo
- Microsoft Learn
- Google Classroom
- Discord
- Apple Human Interface Design

The entire experience should feel polished, smooth, modern, premium, and extremely interactive.

---

# PRIMARY OBJECTIVE

Design dashboards that students and faculty genuinely enjoy using every day.

Every interaction should feel satisfying.

The interface should guide the user naturally without confusion.

The application should feel alive through tasteful animations, transitions, hover effects, and micro-interactions—without becoming distracting.

# FINAL EXPECTATION

The final UI should feel like a premium SaaS product rather than a college project.

Every screen should be highly interactive, visually engaging, and intuitive.

Prioritize usability over decoration. Every animation should have a purpose, every color should support readability, and every layout should adapt gracefully to different screen sizes.

The result should be production-ready, responsive, accessible, and free from layout, overflow, responsiveness, or usability issues.

Build the complete Student Dashboard and Staff Dashboard following this specification with clean, reusable components and a scalable design system suitable for future expansion.
